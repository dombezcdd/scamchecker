# WALLET BOT — учебный Telegram-проект

Это запускаемый демонстрационный проект Telegram-бота + Mini App.

**Важно:** здесь реализован только внутренний демонстрационный учёт единиц (DEMO credits).
Он не принимает настоящую криптовалюту, не создаёт блокчейн-адреса, не отправляет транзакции
и не хранит реальные активы. Курсы обмена условные. Не используйте интерфейс, чтобы создавать
впечатление, будто у пользователя есть реальные USDT, TON, BTC и т. п.

## Возможности

- Telegram-бот на Aiogram 3.
- Mini App на FastAPI + HTML/CSS/JS.
- Внутренние DEMO-балансы: TON, USDT, BTC, ETH, BNB, SOL.
- Администратор может начислить DEMO-кредиты командой `/credit`.
- Администратор может создать одноразовый демонстрационный чек командой `/check`.
- Пользователь может обменивать DEMO-кредиты по фиксированным учебным курсам.
- SQLite для локального запуска.
- Проверка подписи `Telegram.WebApp.initData` на сервере.
- История внутренних операций.

## 1. Создайте Telegram-бота

Через официального @BotFather создайте бота и получите токен.
Узнайте свой Telegram ID (команда `/id` после запуска).

## 2. Установка

Требуется Python 3.10+.

```bash
python -m venv .venv
# Windows:
.venv\\Scripts\\activate
# macOS/Linux:
source .venv/bin/activate

pip install -r requirements.txt
cp .env.example .env
```

Заполните `.env`:
- `BOT_TOKEN` — токен бота.
- `ADMIN_USERNAME` — username владельца без `@` (по умолчанию `memgriefhelp`).\n- `ADMIN_IDS` — числовой Telegram ID (рекомендуется добавить: ID надёжнее username; можно несколько через запятую).
- `BOT_USERNAME` — username бота без `@`.
- `WEBAPP_URL` — HTTPS-адрес Mini App после публикации.

## 3. Запуск локально

В одном терминале:
```bash
uvicorn app:app --host 0.0.0.0 --port 8000
```

В другом:
```bash
python bot.py
```

Для открытия Mini App из Telegram нужен публичный HTTPS URL. Для локального теста
можно использовать временный HTTPS-туннель, но не публикуйте `.env` и не передавайте токен.

## Команды

- `/start` — старт.
- `/id` — показать ваш Telegram ID.
- `/credit USER_ID ASSET AMOUNT` — начислить внутренние DEMO-кредиты.
  Пример: `/credit 123456789 TON 25`
- `/check ASSET AMOUNT` — создать одноразовый чек.
  Пример: `/check USDT 10`

## Подключение Mini App в BotFather

После размещения приложения на HTTPS:
1. Откройте @BotFather.
2. Выберите бота → Bot Settings → Configure Mini App (или Menu Button).
3. Укажите `WEBAPP_URL`.
4. В `.env` укажите тот же адрес и перезапустите бота.

## Безопасность и ограничения

- Не добавляйте реальные депозиты/выводы без отдельной безопасной архитектуры, аудита и юридической проверки.
- Не называйте внутренние DEMO-кредиты настоящей криптовалютой.
- Не просите у пользователей seed-фразы, приватные ключи или коды подтверждения.
- Не выдавайте внутреннее предупреждение приложения за «чёрный список блокчейна».
- Для реальных платежей используйте проверенного платёжного/кастодиального провайдера,
  соблюдайте правила страны и возрастные ограничения, а также требования KYC/AML.
